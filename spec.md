# Learning Elastic timelines

Create a Terraform config to provision an Elastic Cloud instance on Azure, with 16 GB RAM and 8 GB Kibana and 8 GB ML node. 

Also provision a VM on Azure to create synthetic data for use in investigating a repeatable security issue. 

The purpose of the resources are to create a 1-hour demo of: 

Using Timelines in Elastic Security to: 

"Streamline triage and eliminate manual documentation bottlenecks: 

    * Pinning & Investigating: Saving queries, pinning IOCs, and tracking investigation steps directly within Elastic.   

    * Team Collaboration & Handovers: Structuring and naming timelines so historical investigations and accepted behaviors are easily searchable across the team.   

    * Templating: Building reusable timeline templates for recurring alert types."

The customer problem to solve is that analyst notes between investigations are hard to share and manage in Elastic Security.
